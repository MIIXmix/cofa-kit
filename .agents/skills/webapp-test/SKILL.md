# 웹 서비스 테스트

## 1. 자동 테스트 (터미널 실행 결과가 평가 기록으로 남는다)
- 도구: Python이면 pytest + FastAPI TestClient(또는 Flask test_client), Node면 내장 `node --test` + fetch. 새 도구 설치는 최소로.
- 수용 기준 1개당 테스트 1개 이상. 테스트 이름에 수용 기준 번호를 넣는다. 예: `test_AC3_수량0_저장거부`.
- 수용 기준마다 다음 경우를 검토해 해당하는 것만 추가한다:
  정상값 / 빈 값 / 형식 오류 / 경계값(이상·초과 양쪽) / 중복 / 한글·공백 / 대량(100건 이상) / 새로고침·재시작 후 유지.
- 실행 명령 한 줄을 README에 적고, 실행 결과 요약(통과 n / 실패 n)을 NOTES.md 검증 절에 기록한다.
- 실패 테스트를 지우거나 기대값을 결과에 맞춰 바꾸지 않는다. 바꿔야 하면 이유를 COLLAB_LOG.md에 남긴다.

## 2. 서버 연기 확인 (서버 실행 중일 때)
`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:<포트>/<경로>` 로 주요 경로가 200인지 확인한다.

## 3. Browser 수동 점검표 (내가 직접 누른다)
수용 기준마다 한 줄: `경로 | 입력/클릭 | 기대 화면 | 결과(O/X)`. 10줄 이내로 만들어 나에게 준다.
X가 나오면 재현 절차를 적고 수정 단위로 되돌아간다.
