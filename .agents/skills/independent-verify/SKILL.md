# 독립 검증 (공통 가정 오류를 잡는 절차)

1. 메인은 검증할 항목만 정한다: 최종 판정, 핵심 수치(합계·비율·경계 사례), 제외·환산 처리. 메인 결과값은 아직 넘기지 않는다.
2. verifier 서브에이전트를 1개 생성한다. 넘기는 것: 항목 목록, work/ 사본 경로, REQUIREMENTS.md. 넘기지 않는 것: 메인 코드·결과·NOTES.md.
3. verifier가 verify/에 결과와 '해석이 갈린 지점' 목록을 만들면, 그때 메인 결과표를 넘겨 대조시킨다.
4. 불일치 항목마다 원인을 셋 중 하나로 분류한다: (a) 메인 오류 (b) 검증 오류 (c) 요구사항 해석 차이. (c)는 담당자 확인 대상으로 보고한다.
5. NOTES.md '검증' 절에 기록: 검증 항목 수, 일치 수, 불일치 내용과 처리, 검증으로도 못 잡는 한계(두 에이전트가 같은 자료를 같은 방식으로 오독하는 경우 등).
